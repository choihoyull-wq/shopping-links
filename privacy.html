개인정보처리방침

템빨살림 · 콕장터 통합 쇼핑 관리자

공개일 2026년 11월 27일

자동 로그인, 사전 동의 및 채널별 데이터 삭제에 관한 안내는 해당 기능이 관리자에 적용된 뒤부터 적용됩니다.

1. 적용 범위

이 방침은 템빨살림과 콕장터 운영자가 상품을 등록하고 소셜 채널의 댓글을 관리하는 통합 쇼핑 관리자에 적용됩니다. 관리자는 Supabase Auth로 로그인합니다. YouTube 채널을 연결할 때는 Google의 공식 OAuth 승인 화면을 이용하며, 관리자는 Google 계정 비밀번호를 이 서비스에 입력하지 않습니다.

YouTube 기능을 사용하기 전에 관리자 화면에서 이 방침과 YouTube 서비스 약관에 동의해야 합니다. YouTube 기능 이용에는 YouTube 서비스 약관이 적용됩니다. 동의한 방침 버전은 해당 관리자 계정과 브라우저에 기록됩니다.

2. 처리하는 데이터와 사용 목적

  • 관리자 계정 및 상품 정보. 관리자 이메일, 계정 식별자와 로그인 세션은 접속 권한 확인에 사용합니다. 상품명, 번호, 사진, 구매 링크는 상품 등록, 홈페이지 표시, 댓글 답글에 사용할 구매 링크 확인에 사용합니다.
  • Google 및 YouTube API 데이터. 연결한 채널의 식별자와 이름, 등록한 영상의 식별자, 댓글과 답글의 식별자 및 내용, 작성 시각, 작성 채널 식별자와 댓글·답글 수를 채널 구분, 댓글 조회, 답글 대상 선정, 중복 답글 방지 및 처리 결과 표시에 사용합니다.
  • YouTube 자동 답글. 운영자가 해당 채널의 자동 답글을 활성화하고 영상에 상품을 연결하면, 관리자 페이지가 열려 있는 동안 설정한 주기로 조건에 맞는 댓글을 확인합니다. 답글을 게시할 때는 원본 댓글의 식별자와 답글 문구를 YouTube로 전송합니다. 게시된 답글은 해당 영상의 댓글 영역에 공개될 수 있습니다.
  • 인스타그램 댓글 조회. 운영자가 기존 Meta 조회 기능을 사용할 때 계정 식별자와 사용자 이름, 릴스의 식별자·캡션·유형, 댓글 및 답글 식별자를 계정 확인, 상품 연결 및 댓글·답글 수 집계에 사용합니다.

3. 저장과 보호

  • YouTube 자동 로그인 사용 시. 해당 채널의 Access Token과 Refresh Token은 Supabase 서버에서 AES-GCM으로 암호화해 저장합니다. 연결 정보에는 관리자와 채널의 식별 정보, 채널 이름, Access Token 만료 시각, 자동 답글 활성화 상태가 포함됩니다. 암호화 키와 OAuth 클라이언트 비밀값은 서버의 비밀값 저장소에 보관합니다. 관리자 브라우저는 인증된 요청으로 해당 채널의 단기 Access Token을 받아 메모리에서 사용합니다. Refresh Token은 서버에서만 처리합니다.
  • 일반 YouTube 연결 및 브라우저 저장소. 자동 로그인 유지를 선택하지 않은 일반 연결의 단기 Access Token과 연결 상태는 브라우저 세션 저장소에 보관될 수 있습니다. 브라우저의 로컬 저장소에는 채널·영상·상품 연결, 조회 주기와 자동 답글 처리 이력(댓글 문구, 답글 또는 오류, 처리 시각 등)이 남습니다. 운영자가 내려받은 CSV는 다운로드한 기기에 남습니다.
  • 인스타그램. 조회용 Meta Access Token은 입력한 관리자 페이지의 메모리에서 사용합니다. 릴스와 상품의 연결 정보는 브라우저 로컬 저장소에 남습니다.

관리자 페이지와 API 통신에는 HTTPS를 사용합니다. Google 연결 정보는 인증된 관리자와 해당 채널을 구분하여 처리합니다.

브라우저에 보관하는 YouTube 답글 처리 이력은 기록 후 29일이 지나면 관리자 화면이 열려 있을 때나 다음에 열 때 정리합니다. 닫혀 있는 브라우저와 내려받은 CSV는 해당 기기에서 직접 정리할 수 있습니다. 서버는 토큰을 갱신할 때 Google에서 채널 정보를 다시 확인합니다. 시간별 정리 작업은 만료된 인증 요청과 토큰 만료 시각이 28일 이상 경과한 연결을 삭제합니다.

4. 외부 서비스 및 Google 데이터 이용 제한

Google과 YouTube는 권한 승인, 토큰 갱신, 댓글 조회·답글 게시 요청을 처리합니다. Supabase는 관리자 인증, 데이터 저장 및 서버 기능을 제공하고, GitHub Pages는 관리자 웹페이지를 제공합니다. 선택적으로 인스타그램 조회를 사용하는 경우 해당 조회 요청은 Meta가 처리합니다.

Google API에서 받은 정보의 이용과 전송에는 Google API Services User Data Policy의 Limited Use 요구사항을 적용합니다. Google 데이터는 위에서 설명한 관리자 기능을 제공하는 데 사용하며, 판매하거나 광고 타기팅, 개인 프로파일링 또는 범용 AI 모델 학습에 이용하지 않습니다.

5. 연결 해제, 삭제 요청 및 문의

  1. 해당 채널의 YouTube 로그아웃 · 데이터 삭제를 누르고 확인하면 그 채널의 자동 답글을 중지하고 브라우저에 저장된 연결, 영상과 상품의 연결, 답글 이력을 삭제합니다. 서버는 해당 채널의 진행 중인 인증 요청을 삭제한 뒤 Google 권한 철회를 요청하고 저장된 인증 정보와 연결 레코드를 삭제합니다. 상품 원본과 다른 채널의 설정은 이 삭제 범위에 포함되지 않습니다.
  2. 서버 삭제 실패 안내가 나오면 같은 화면에서 다시 시도하거나 아래 문의처에 요청하세요. Google 계정의 서드 파티 접근 권한 설정에서도 권한을 철회할 수 있습니다. 이후 갱신에서 Google이 권한을 거부하면 서버에서 해당 연결을 삭제하고, 관리자 화면에서도 확인된 연결의 브라우저 데이터를 삭제합니다.
  3. 다른 기기에 남아 있는 브라우저 기록이나 내려받은 CSV는 해당 기기에서 삭제할 수 있습니다. 서비스에 보관된 YouTube 데이터의 삭제는 관리자 화면에서 직접 요청하거나 아래 문의처로 요청하세요. 접수한 삭제 요청은 계정과 채널을 확인한 뒤 가능한 한 빨리, 늦어도 요청일로부터 7일 이내에 처리합니다.
  4. 관리자에 저장된 연결이나 기록을 삭제해도 YouTube에 이미 게시된 답글은 남습니다. 게시된 답글을 삭제하려면 YouTube에서 해당 답글을 관리하세요.
